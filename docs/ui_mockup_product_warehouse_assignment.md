# UI Mockup: Product-Warehouse Assignment Management

## Overview
This document describes the user interface for managing product-to-warehouse assignments with per-warehouse planning data.

## Validation Messages

### Required Fields
- "يرجى اختيار المنتج"
- "يرجى اختيار المستودع"
- "يرجى تحديد طريقة التزويد"
- "يرجى تحديد الحد الأدنى للمخزون"

### Business Logic Validation
- "هذا المنتج مرتبط بالفعل بهذا المستودع"
- "تاريخ التفعيل يجب أن يكون في المستقبل أو اليوم"
- "تاريخ الانتهاء يجب أن يكون بعد تاريخ التفعيل"
- "الحد الأقصى يجب أن يكون أكبر من الحد الأدنى"
- "مخزون الأمان يجب أن يكون أقل من الحد الأدنى"

### Success Messages
- "تم إنشاء ربط المنتج بالمستودع بنجاح"
- "تم تحديث بيانات التخطيط بنجاح"
- "تم تفعيل إعادة الطلب التلقائي"
